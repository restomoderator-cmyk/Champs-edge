# Папка для файлов художника и композитора

Положите сюда файл с именем из таблицы, пересоберите игру (`python3 build_next.py`), и она начнёт использовать его вместо заглушки. Нет файла: рисует и играет кодом, как раньше.

- Картинки: имена и размеры в `docs/brif-hudozhnik.md`, раздел «Файлы, которые игра подхватит сама».
- Звуки и музыка: имена в `docs/brif-kompozitor.md`, раздел «Имена файлов».

Форматы: PNG для картинок, WAV или MP3 для звука. Файлы вшиваются внутрь страницы игры, поэтому музыку лучше присылать в MP3, а короткие звуки в WAV.
