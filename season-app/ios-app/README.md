# Сборка приложения для айфона

Это заготовка, а не готовый проект. Она не проверена на маке: у меня его нет. Первый запуск почти наверняка потребует мелких правок, и делать его лучше вместе, шаг за шагом.

## Как это устроено

Игра это одна страница, которая работает без интернета. Приложение для айфона это тонкая обёртка: окно, в котором открыта эта страница. Обёртку собирает стандартный инструмент Capacitor. Прогресс игрока хранится на телефоне, как и в браузере.

## Что нужно на маке

- Xcode из App Store.
- Node.js.
- CocoaPods (нужен Capacitor для iOS).
- Вход в Xcode под вашим Apple ID разработчика.

## Шаги

Все команды выполняются в терминале на маке, в папке репозитория.

1. Собрать страницу игры:

       python3 season-app/ios-app/make_www.py

   Появится `season-app/ios-app/www/index.html`.

2. Один раз создать обёртку (в папке `season-app/ios-app`):

       cd season-app/ios-app
       npm init -y
       npm install @capacitor/core @capacitor/cli @capacitor/ios
       npx cap init "Сезон" ВАШ.ИДЕНТИФИКАТОР --web-dir www
       npx cap add ios

   `ВАШ.ИДЕНТИФИКАТОР` это идентификатор приложения в обратной записи домена. Его выбираете вы, и он должен совпасть с тем, что заведён в кабинете разработчика Apple. Поменять его после выпуска нельзя.

3. После каждой новой сборки игры:

       python3 make_www.py
       npx cap copy ios

4. Открыть проект в Xcode:

       npx cap open ios

   В Xcode: выбрать свою команду разработчика в настройках подписи, подключить айфон, нажать запуск.

5. Отправка в App Store делается из Xcode (Product, Archive). К этому моменту должны быть готовы иконка, снимки экрана, описание и политика конфиденциальности: список в `docs/appstore-chto-nuzhno.md`.

## Что надо настроить в проекте Xcode руками

- Только вертикальная ориентация.
- Иконка приложения и экран запуска.
- Название под иконкой.
- Версия и номер сборки.

## Что проверить на настоящем айфоне в первую очередь

Этого нельзя проверить ни на компьютере, ни ботами:

1. Два пальца одновременно: левый ведёт, правый тянет.
2. Двойной тап левым (стержень) и одиночный (своё слово).
3. Звук: включается после первого касания, не обрывается при блокировке экрана.
4. Вибрация. В обёртке она может не работать так, как в браузере: тогда её надо подключать отдельным модулем Capacitor.
5. Вырез экрана и нижняя полоса жестов не закрывают игру.
6. Прогресс сохраняется после закрытия приложения и после перезагрузки телефона.

## Чего в этой папке нет и не будет

Сертификатов, ключей подписи, паролей, профилей. Они живут на вашем маке и в кабинете Apple. Папки `www`, `ios`, `node_modules` и настройки Capacitor в репозиторий не попадают: они создаются на маке заново.

## Чего здесь ещё нет

- Родительского входа и покупки. Без них приложение можно собрать и проверить, но нельзя выпускать с платным продолжением.
- Модуля покупок Apple.
