# Задание композитору: музыка и звуки для игры «Сезон»

Сейчас вся музыка и все звуки в игре синтезируются кодом как заглушка. Ниже полный список по текущей сборке.

## Общее

- Игра про то, как сохранять холодную голову в хоккее. Звук должен помогать собраться, а не взвинчивать.
- Стиль под пиксельную графику: чиптюн или близкое, но мягче и теплее, чем резкие «восьмибитные» пищалки. Играть будут подростки, часто в наушниках.
- Игрок слышит музыку матча сотни раз. Она не должна надоедать на третьей минуте.
- Громкость по умолчанию тихая. Звуки событий важнее музыки.

## Музыка

| Трек | Где | Длина петли | Настроение |
|---|---|---|---|
| Меню | Главный экран, вводные, решения | 30-60 с | Спокойное, собранное |
| Матч | Игра на льду | 60-90 с | Движение, ровный пульс, без нагнетания |
| Матч, давление | Когда полоса давления соперника выше половины | слой поверх трека матча | Тревога нарастает, темп тот же |
| Овертайм и буллиты | Овертайм, серия буллитов | 30-45 с | Тишина перед решающим моментом |
| Победа | Итог матча | 5-8 с, не петля | Радость без пафоса |
| Поражение | Итог матча | 5-8 с, не петля | Спокойно, без издёвки и без трагедии |
| Дерби | Матч 7 | 60-90 с | Главный матч месяца, плотнее обычного |

Важное требование: во время выдоха музыка приглушается на три четверти (это делает код). Трек матча должен хорошо звучать и тихо, и в полную громкость.

Хорошо бы: трек матча из слоёв (бас, ритм, мелодия отдельными файлами), чтобы код мог убирать и добавлять слои по состоянию головы игрока.

## Звуки

| Звук | Когда | Длина | Каким должен быть |
|---|---|---|---|
| Нажатие | Любая кнопка | до 0,1 с | Тихий щелчок |
| Приём паса | Шайба пришла на крюк | 0,1 с | Чёткий стук: по нему игрок понимает, что можно бросать |
| Выдох | Пока игрок держит палец | петля 2-3 с | ТИХИЙ выдох. Не шум, не шуршание: настоящий мягкий выдох. Первый тестер сказал про заглушку «как шуршание пакета» |
| Выдох готов | Линия сжалась в точку | 0,1 с | Тонкий чистый сигнал, «пора» |
| Бросок кистевой | Отпустил палец после оттяжки | 0,1 с | Щелчок клюшки |
| Щелчок | Быстрый тап, сильный бросок | 0,15 с | Громче и резче кистевого |
| Гол | Обычный гол | 0,5 с | Короткая радость; при серии голов тон чуть выше с каждым |
| Идеальный гол | Гол после полного выдоха | 0,6 с | Отличается от обычного с первой ноты |
| Трибуны | После гола | 1 с | Короткий гул |
| Промах | Мимо, сейв, блок | 0,15 с | Глухо, без издёвки |
| Штанга | Попал в штангу | 0,2 с | Звон |
| Гол соперника | Нам забили | 0,4 с | Низко, тяжело |
| Потеря | Отобрали, перехват, вратарь выбил | 0,2 с | Короткий сухой звук |
| Стержень | Включил стержень | 0,7 с | Самый «большой» звук в игре: голова остыла разом |
| Стержень заряжен | Зарядился на льду | 0,2 с | Тихий подъём |
| Шум трибун | Чужие трибуны гудят | петля 3-4 с | Мешающий гул, от которого хочется избавиться |
| Своё слово | Игрок убрал шум | 0,3 с | Шум обрывается, тишина |
| Сирена | Конец отрезка | 0,6 с | Хоккейная сирена, коротко |

## Вибрация

К звукам «приём паса», «выдох готов», «гол» и «стержень» код добавляет короткую вибрацию. Звук должен читаться и без неё.

## Формат сдачи

- WAV, 44,1 кГц, 16 бит; петли без щелчка на стыке.
- Отдельный файл на каждый звук и слой, имена латиницей по образцу `sfx_pass.wav`, `music_match_bass.wav`.
- Громкости выровнены между собой: приведу в игре, но исходники не должны отличаться в разы.

## Порядок

Сначала выдох, приём паса и два гола: на них держится ощущение игры. Потом трек матча. Остальное после.

## Чего не делать

- Не использовать чужие мелодии, гимны клубов и узнаваемые стадионные кричалки.
- Не делать поражение обидным.
- Не использовать голос со словами: слово у каждого игрока своё.

## Имена файлов

Как только файл с таким именем появится в папке `assets/`, игра начнёт играть его вместо синтезированной заглушки. Можно присылать по одному. Формат WAV или MP3; музыку лучше в MP3, потому что файлы вшиваются в игру.

| Имя файла (без расширения) | Звук из таблицы выше |
|---|---|
| `sfx_tap` | Нажатие |
| `sfx_pass` | Приём паса |
| `sfx_breath` | Выдох, петля |
| `sfx_full` | Выдох готов; он же «стержень заряжен» и «своё слово» |
| `sfx_shot` | Бросок, кистевой и щелчок |
| `sfx_goal` | Гол |
| `sfx_top` | Идеальный гол |
| `sfx_bad` | Промах, потеря |
| `sfx_post` | Штанга |
| `sfx_riv` | Гол соперника; он же начало шума трибун |
| `sfx_core` | Стержень; он же начало потока |
| `sfx_end` | Сирена |
| `music_menu` | Музыка меню, петля |
| `music_match` | Музыка матча, петля |

Сейчас в игре двенадцать звуковых событий, а в списке выше восемнадцать: несколько звуков пока делят одно событие (например, щелчок и кистевой бросок звучат одинаково). Когда появятся первые файлы, разведу их по отдельным именам. Треки «давление», «овертайм», «победа», «поражение» и «дерби» пока не подключены: для них нужны отдельные события в игре, добавлю вместе с первыми файлами.
