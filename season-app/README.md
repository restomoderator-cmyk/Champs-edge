# Сезон: прототип игры (матчи 1-4)

Рабочая папка игры. На сайт не попадает: в основную ветку без владельца не сливается.

- `base.html`: экраны, тексты, звук, состояние.
- `engine.js`: матч (управление двумя пальцами, голова, выдох, давление соперника, овертайм, буллиты) и боты-тестировщики.
- `patch2.py`: правки поверх base.html и вставка engine.js.
- `build.py`: сборка в одну страницу `season.html` (шрифты и спрайты берутся из сайта).
- `simrun.js`: команда ботов, сотни матчей без экрана. `node simrun.js 80`
- `bot2.js`: бот на настоящем экране, проходит все четыре матча. `node bot2.js tap 14`
- `so.js`: проверка овертайма и буллитов.
- `engine-next.js`, `build_next.py`, `patch-next.py`: рабочая копия игры со всем новым, сборка в `season-next.html`.
- `simcheck.js`: проверка баланса ботами, PASS или FAIL. `python3 build_next.py && node simcheck.js 200`
- `PLAN.md`, `REPORT.md`: план работы и отчёт.
- `docs/`: карта игры, концепция, опросник.
- `old-prototype/`: первая версия, на которой шла первая фокус-группа.

Все проверки рабочей копии одной командой (около семи минут): `sh check_all.sh`. Печатает «ВСЁ В ПОРЯДКЕ» или что не прошло.

Сборка и проверка версии тестировщиков:

    python3 build.py && node --check check.js && node simrun.js 80

Ссылка, по которой играют тестировщики, публикуется отдельно и из этой папки сама не обновляется.
