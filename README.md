# Champs-edge

Лендинг программы **Champion's Edge** («Грани Чемпионов») в стиле 16-битных игр.

Статический сайт без сборки и зависимостей: откройте `index.html` в браузере
или запустите локальный сервер:

```
python3 -m http.server 8000
```

## Структура

- `index.html` - разметка и тексты разделов
- `css/style.css` - стили
- `js/main.js` - данные (пути, уровни, инвентарь), пиксельная графика, сцена с персонажем, звук
- `js/site-params.js` - Яндекс Метрика (после согласия посетителя), параметры адреса `?r=`, `?role=`, `?path=`, UTM
- `server/form-handler/` - функция для Yandex Cloud, которая принимает анкету на созвон (на сайт не выкладывается)
- `js/voice-pro.js` - редакция для агента, клуба и тренера: словарь «строка для игрока → строка на „вы“»
- `js/sport-tennis.js` - теннисная версия: словарь «хоккейная строка → теннисная»
- `js/i18n-en.js` - английские тексты: словарь «русская строка → перевод»
- `img/` - картинка для превью ссылки и значки сайта
- `fonts/` - пиксельные шрифты Press Start 2P и Handjet (лицензия OFL)

## Что нужно настроить

- **Контакты.** Ссылка Telegram задаётся в `index.html` у кнопки `#cta`, почта там же и в `js/main.js` (`MAIL`).
  Роль посетителя и выбранный путь подставляются в текст сообщения автоматически.
- **Недели 7-12** показаны на карте как закрытые уровни: по задумке они открываются в процессе игры.
  Открытые уровни задаются в массиве `PHASES` в `js/main.js`.
- **Домен.** Сайт публикуется через GitHub Pages на `edgechamps.com` (файл `CNAME`). Адрес также прописан
  в `index.html` в тегах `og:url`, `og:image`, `twitter:image` и `canonical`: при смене домена поменяйте его там.
- **Языки.** Сайт открывается на русском или английском по языку браузера; посетитель переключает язык кнопкой
  в меню, выбор запоминается. Ссылка сразу на английскую версию: `https://edgechamps.com/?lang=en`.
  Меняя русский текст в `index.html` или `js/main.js`, добавьте перевод новой строки в `js/i18n-en.js`,
  иначе в английской версии она останется по-русски.
- **Поисковики.** В `index.html` заданы заголовок, описание, Open Graph, разметка организации (JSON-LD) и блок
  `<noscript>` с кратким содержанием сайта обычным текстом. Рядом лежат `robots.txt` и `sitemap.xml`.
  Меняя состав программы, пути или контакты, поправьте и текст в `<noscript>`.
- **Страницы видов спорта.** `https://edgechamps.com/hockey/` и `https://edgechamps.com/tennis/` сразу открывают
  свою игру, у каждой свой заголовок и описание для поисковиков. Файлы `hockey/index.html` и `tennis/index.html`
  собираются из `index.html`: после любой правки главной страницы запустите `python3 tools/make-sport-pages.py`.
  Руками эти два файла не правят.
- **Виды спорта.** На заставке посетитель выбирает хоккей или теннис, выбор запоминается. Корт, подача и теннисист
  нарисованы в `js/main.js` (ветки с `TENNIS`), отличающиеся тексты лежат в `js/sport-tennis.js`.
  Ссылка сразу на теннисную версию: `https://edgechamps.com/?sport=tennis`.

## Аналитика, персональные ссылки и анкета

- **Метрика.** Счётчик 114286443 подключается в `js/site-params.js` и запускается только после кнопки «Давай»
  в уведомлении о cookie. Выбор хранится в `localStorage` под ключом `ce_analytics`.
  Проверка: `https://edgechamps.com/?_ym_debug=1`, принять cookie, смотреть консоль браузера.
- **Цели.** В кабинете Метрики нужно вручную создать цели типа «JavaScript-событие» с такими идентификаторами:
  `cta_telegram`, `cta_email`, `form_open`, `form_submit_ok`, `role_selected`, `path_selected`,
  `section_role`, `section_path`, `section_about`, `section_science`, `section_how`, `section_start`.
- **Ссылки.** `?r=ce_xxxxxxxx` (код из 8 символов `a-z`, `2-9`) запоминается на 90 дней, уходит в Метрику
  параметром `r_code` и строкой «код: ...» в текст обращения. `?role=player|agent|club|coach` и
  `?path=young|peak|veteran` (или `talent|hero|legend`) сразу выбирают роль и путь. UTM-метки доезжают до анкеты.
  Пример: `https://edgechamps.com/?r=ce_k7m4q2xp&role=agent&path=hero&utm_source=tg`.
- **Анкета на созвон.** Кнопка анкеты в блоке записи появится, когда в `js/main.js` будет задан `FORM_ENDPOINT`:
  публичный адрес функции из `server/form-handler/` (там же инструкция). Пока адрес пустой, анкета скрыта.
  Посмотреть вёрстку без сервера: `?form=test`.
- **Тексты согласия** в разделе `#privacy` в `index.html`: это черновик, до публикации его нужно сверить
  с юристом и заменить плейсхолдер оператора.

## Редакции для ролей

Игрок читает сайт на «ты». Агент, клуб и тренер видят свою редакцию: обращение на «вы», об игроке в третьем лице,
свои реплики проводника, блок «Что это даёт», свои шаги и текст записи.

- Тексты ролей лежат в `js/main.js` в `ROLE_PRO`; общие замены «ты → вы» в `js/voice-pro.js`.
- При переходе между игроком и остальными ролями страница перезагружается в нужной редакции.
- Новую строку для игрока с обращением на «ты» нужно продублировать в `js/voice-pro.js`, а её перевод
  в `js/i18n-en.js`, иначе агент, клуб и тренер увидят обращение на «ты».
