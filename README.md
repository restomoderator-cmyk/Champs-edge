# Champs-edge

Лендинг программы **Champion's Edge** («Грани Чемпионов») в стиле 16-битных игр.

Статический сайт без сборки и зависимостей: откройте `index.html` в браузере
или запустите локальный сервер:

```
python3 -m http.server 8000
```

## Структура

- `index.html` - разметка и тексты разделов
- `css/style.css` - стили
- `js/main.js` - данные (пути, уровни, инвентарь), пиксельная графика, сцена с персонажем, звук
- `fonts/` - пиксельные шрифты Press Start 2P и Handjet (лицензия OFL)

## Что нужно настроить

- **Ссылка для записи** задаётся в `index.html` у кнопки `#cta` (ссылка `t.me/...`
  или `mailto:...`). Выбранный путь чемпиона подставляется в текст сообщения автоматически.
- **Недели 7-12** показаны на карте как закрытые уровни: по задумке они открываются в процессе игры.
  Открытые уровни задаются в массиве `PHASES` в `js/main.js`.
