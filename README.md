# Champs-edge

Лендинг программы **Champion's Edge** («Грани Чемпионов») в стиле 16-битных игр.

Статический сайт без сборки и зависимостей: откройте `index.html` в браузере
или запустите локальный сервер:

```
python3 -m http.server 8000
```

## Структура

- `index.html` - разметка и тексты разделов
- `css/style.css` - стили
- `js/main.js` - данные (пути, уровни, инвентарь), пиксельная графика, сцена с персонажем, звук
- `js/i18n-en.js` - английские тексты: словарь «русская строка → перевод»
- `img/` - картинка для превью ссылки и значки сайта
- `fonts/` - пиксельные шрифты Press Start 2P и Handjet (лицензия OFL)

## Что нужно настроить

- **Контакты.** Ссылка Telegram задаётся в `index.html` у кнопки `#cta`, почта там же и в `js/main.js` (`MAIL`).
  Роль посетителя и выбранный путь подставляются в текст сообщения автоматически.
- **Недели 7-12** показаны на карте как закрытые уровни: по задумке они открываются в процессе игры.
  Открытые уровни задаются в массиве `PHASES` в `js/main.js`.
- **Домен.** Сайт публикуется через GitHub Pages на `edgechamps.com` (файл `CNAME`). Адрес также прописан
  в `index.html` в тегах `og:url`, `og:image`, `twitter:image` и `canonical`: при смене домена поменяйте его там.
- **Языки.** Сайт открывается на русском или английском по языку браузера; посетитель переключает язык кнопкой
  в меню, выбор запоминается. Ссылка сразу на английскую версию: `https://edgechamps.com/?lang=en`.
  Меняя русский текст в `index.html` или `js/main.js`, добавьте перевод новой строки в `js/i18n-en.js`,
  иначе в английской версии она останется по-русски.
